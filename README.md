# 📱 ItemHub Android App

An Android application built using **Kotlin + Firebase** for managing items with authentication and Firestore database.

---

## 🚀 Features

- 🔐 User Signup & Login (Firebase Auth)
- 🔑 Forgot Password functionality
- 📦 Add / Edit / Delete Items
- ☁️ Cloud storage using Firebase Firestore
- 📋 Dashboard to view all items
- 🎨 Clean and modern UI design

---

## 🛠️ Tech Stack

- Kotlin (Android)
- Firebase Authentication
- Firebase Firestore
- MVVM Architecture
- Android Studio

---

## 📂 Project Structure

- Activities: Login, Signup, Dashboard, Splash, Forgot Password
- MVVM: ViewModel + Repository pattern
- Adapter: RecyclerView adapter for items
- Models: User & Item data classes
